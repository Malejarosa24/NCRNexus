# NCRNexus

Sistema web de soporte técnico desarrollado con JSP, Servlets y MySQL para la gestión de tickets e incidencias.

---

## 🛠 Tecnologías utilizadas

- Java
- JSP
- Servlets
- MySQL
- Apache Tomcat
- Apache NetBeans
- HTML y CSS
- Git y GitHub

---

## ⚙ Funcionalidades

✅ Registrar tickets  
✅ Actualizar tickets desde MySQL  
✅ Cambiar estado de tickets  
✅ Eliminar tickets  
✅ Buscar tickets  
✅ CRUD completo  

---

## 🗄 Base de datos

Base de datos:

```sql
ncrnexus
```

Tabla principal:

```sql
tickets
```

---

## 🚀 Cómo ejecutar el proyecto

1. Clonar el repositorio:

```bash
git clone https://github.com/Malejarosa24/NCRNexus.git
```

2. Abrir el proyecto en Apache NetBeans.

3. Configurar Apache Tomcat.

4. Crear la base de datos MySQL llamada:

```sql
ncrnexus
```

5. Importar el script SQL de la tabla `tickets`.

6. Ejecutar el proyecto desde NetBeans.
